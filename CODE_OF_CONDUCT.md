# Code of conduct

Waldo adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. It applies in this repository, in its issues and pull requests, and anywhere you speak for the project.

In short: be kind, assume good faith, and keep it about the work. Harassment of any kind is not welcome here.

Report a problem to info@justusewaldo.com. Reports stay private. The maintainers read every one and act on it.
